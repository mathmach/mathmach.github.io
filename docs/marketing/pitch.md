## 🔥 Hacker News — "Show HN" title

> Show HN: Wind Comic – Open-source multi-agent AI turns one sentence into a finished short drama

**First comment (background):**

> Author here. After watching black-box AI video tools give us 5-second clips when we actually wanted a complete short film, I built Wind Comic as a multi-agent pipeline.
>
> Key non-obvious technical choices:
>
> 1. **Style Bible Frame as visual reference** for every subsequent shot. This eliminates visual style drift across shots.
> 2. **Character DNA as natural-language anchor.** We run each character's turnaround through a Vision LLM to extract structured features (eye shape, jaw angle, hair style, signature outfit), then inject as natural language into every shot prompt that contains the character, giving the model redundant anchors.
> 3. **Strip dialogue from the video prompt; burn subtitles in post.** Asking video models to render characters directly produces garbled glyphs. We strip text prompts and bake subtitles with ffmpeg `subtitles` filter + system font discovery.
> 4. **Typed WebSocket presence for real-time multiplayer.** Lightweight presence handles cursors and tab awareness; PostgreSQL segment locks ensure transactional edit concurrency.
> 5. **Robust architecture.** Production intelligence powered by Google Gemini and rendering orchestrated via ComfyUI.
>
> TypeScript strict, MIT.

**Title:**

**Body:**

I'm sharing **Wind Comic** — an open-source multi-agent short-form drama pipeline. The core idea: short-form drama needs multiple specialized agents handing off with explicit consistency contracts, not one monolithic model trying to do everything.

The 8 agents:

1. **Director** — story plan, character roles, style keywords
2. **Writer** — McKee 3-act + short-drama trope templates, hook-first shot 1
3. **Style Bible** — canonical key-art frame, locks visual identity for all subsequent shots
4. **Character Designer** — turnaround sheets + 8-dim DNA via Vision LLM
5. **Scene Designer** — concept art for each location
6. **Storyboard** — per-shot images with Cameo Vision retry (<75 → regen) and Style Audit (<70 → regen)
7. **Video Producer** — ComfyUI generation orchestration
8. **Editor** — j-cut / l-cut on emotional beats, per-act BGM, ffmpeg subtitle burn

On top of the pipeline: a **multi-track Cinema Timeline** with real-time multiplayer (live cursors, PostgreSQL segment locks, presence chips). Plus comments+@mentions, project invites with viewer/commenter/editor roles, single-shot regen with reference image upload.

Tech: Next.js + TypeScript strict + PostgreSQL + Prisma + Web Audio API + WebSocket presence + ComfyUI + Google Gemini. MIT.

GitHub: https://github.com/ChrisChen667788/wind-comic
