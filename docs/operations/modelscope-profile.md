### Card 5: Subtitle Burner ✍️

> Add real subtitles to the video in post-production. Uses ffmpeg subtitles filter + libass + automatically finds system subtitle fonts. Synchronously removes text from the video prompt + adds a strong negative prompt to prevent the model from drawing text. v2.22 is now available.

### Chinese Version

What is Wind Comic?

Wind Comic is an **open-source multi-agent AI short drama generation pipeline**. Input a creative idea (e.g., "A reborn CEO exposes his ex-fiancee's wedding scam in the street"), and eight AI agents work together to gradually produce: script → character three-view drawings → scene concept art → multi-shot storyboard → final video → voice-over + background music + Chinese subtitles → final mp4. The entire process runs on your own machine, orchestrating Google Gemini for intelligence and ComfyUI for local video/audio generation.

Why not just another "AI video" tool?

Mainstream AI video tools are all black-box models that output short videos based on input prompts. Pain point:

- A single continuous shot cannot be used to create a "6-shot short drama".
- Character cross-camera face change
- The art style is different in each shot
  Chinese subtitles are all garbled.
- Unable to collaborate with multiple people in real time
- Vendor lock-in, your prompt feeds someone else's model.

Wind Comic takes the opposite approach: **pipeline + multiple agents + strict contracts**. Each agent is an expert, communicating using structured data (not just random text). Writers only care about the McKee three-act structure and short trope; character designers only care about three-view drawings and DNA extraction; storyboard artists only care about vision audits and stylistic consistency. If any link in the chain goes wrong, we have a "rebirth/backup/fallback" mechanism.

**Core Technology Highlights**

1. **Style Bible Frame** — After the director has finished planning, render a canonical "key art" frame, which then serves as the first `--sref` for all subsequent storyboards. This is equivalent to "determining the poster first, then filming," turning off 60% of the stylistic variation.

2. **Character DNA + Cameo Vision Retry** — Extracting 8-dimensional structures (eye shape/jaw/nose shape/mouth shape/hairstyle/hair color/skin tone/signature clothing) from three-view images using Vision LLM, injecting them as natural language anchors into each entrance shot. Adding cameo-vision-retry: If the character's match score in a certain shot is <75, automatic respawning occurs, and the character's face is redrawn with improved color depth. Actual face match testing shows an average score of 82, while the industry average for cref+sref is 65.

3. **Truly Usable Subtitles** — The AI ​​video model renders all in-frame text as gibberish. Our approach: Remove dialogue text from the video prompt + apply a strong negative prompt (`--no text --no captions --no calligraphy`) to force the model to only draw the "character speaking" action. Then, in post-production, use ffmpeg `subtitles` filter + libass + system subtitle font to truly render the subtitles.

4. **Logic Pro-style multi-track timeline** — 3-track layout (storyboard/BGM/subtitles), drag to change time, double-click to change subtitle text, drag the edge to change duration, automatic snapping to neighboring tracks, true BGM waveform (Web Audio API decode). Add a layer of **real-time multi-user collaboration**: WebSocket presence + PostgreSQL segment locks, where you can see other users' mouse cursors + name tags + which tab they are in below their avatars, and transactional locks prevent two people from editing the same section.

5. **Google Gemini Native Intelligence** — Google Gemini drives the writer, director, and auditor agents with structured JSON contracts and multi-agent reasoning out of the box. Zero code changes required.

- **Content Marketing Team**: Brand Consistency (Style Bible Lock) + True Rendering of Chinese Subtitles + Multi-person Editing (WebSocket Real-time)
