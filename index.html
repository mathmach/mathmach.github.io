Foundational Methodology

Computer Science as an Empirical Discipline.

Architecture is not aesthetic intuition; it is mathematical trade-off optimization under hard physical constraints. Every system I build obeys formal invariants across lifecycle, concurrency, and modularity.

01 / SYSTEMS LIFECYCLE

ISO/IEC/IEEE 15288 & Boehm's V&V Formalism

Systems are decomposed into formal Agreement, Project-Enabling, Technical Management, and Technical Processes. Following Barry Boehm (1981), we separate Verification ("Are we building the product right?" via automated deterministic test suites and AST grounding) from Validation ("Are we building the right product?" via Design Science Research artifact utility). Defect mitigation costs scale exponentially; we catch defects at specification time.

02 / COMPUTATIONAL ASYMPTOTICS

Landau Complexity & Little's Law

Hot paths are strictly constrained to $\mathcal{O}(1)$ hash lookups or $\mathcal{O}(\log n)$ balanced tree operations. Concurrency and queuing buffers obey Little's Law ($L = \lambda W$) and Neil Gunther's Universal Scalability Law (USL) to prevent retrograde throughput collapse.

03 / MODULAR ISOLATION

Hexagonal Ports & Pure Domain

Alistair Cockburn's Hexagonal Architecture enforces zero infrastructure leakage into core business rules. Adapters are swappable, side-effects are bounded, and domains remain 100% testable in pure memory.

04 / DISTRIBUTED PRAGMATISM

PACELC, FLP Impossibility & Transactional Outbox

Distributed systems operate under asynchronous network realities. Rejecting the 8 Fallacies of Distributed Computing, state synchronization leverages the Transactional Outbox Pattern and Compensating Sagas rather than fragile 2-Phase Commit protocols. Every mutation is backed by an Idempotency Ledger and ARIES-grade recovery semantics.

CASE STUDY / EMPIRICAL AUDIT IN REAL-TIME

How We Eliminate AI Hallucinations at the Source

During our academic reference audit, a standard generative query hallucinated synthetic Google Books IDs (e.g. id=zrkqAAAAMAAJ, id=f_pEAAAAMAAJ which opened a Russian historical novel) and redirected IEEE paths. Instead of accepting plausibility, our protocol deployed verify-references.py to test live HTTP headers, scrape DOM <title> elements, and query the official Crossref REST API. Every false citation was trapped, purged, and replaced with peer-reviewed DOIs and unblocked primary sources.

✕ The Naive AI Default (Unchecked Hallucination)
  • • Generates synthetic book IDs (id=f_pEAAAAMAAJ) that lead to 404s or unrelated books.
  • • Uses masked error handling: .catch(() => fallback) hiding broken dependencies.
  • • Speculates method signatures instead of checking AST on disk.
  • • Leaves partial refactorings across repos, creating "wave" prompting friction.
✓ Matheus's Deterministic Protocol (Zero Speculation)
  • • AST & Symbol Grounding: Inspects live TypeScript/Python AST before writing code.
  • • Automated Verification Engines: Proves claims via real HTTP requests & Crossref APIs.
  • • Zero Fallback Debt: Strict parsing (Zod/Pydantic) with zero silent swallowing.
  • • Exhaustive Refactoring: 100% of references updated in a single turn.
